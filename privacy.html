眼科動画ルーチン（eye-video-routine）

プライバシーポリシー

運営：眼科動画ルーチン 運営者　／　制定日：2026年10月10日

眼科動画ルーチンの運営者（以下「当方」）は、当方が自分の作業のために使う自動化ツール「眼科動画ルーチン」（以下「本ツール」）における情報の取扱いを、以下のとおり定めます。

1. 本ツールについて

本ツールは、当方が作成した患者さんとご家族向けの眼科の説明動画を、当方自身の YouTube チャンネルに投稿するための、当方専用のツールです。当方のコンピューター上でのみ動作し、当方以外の方が利用することはありません。本ツールが Google アカウントへのアクセスを求めるのは、当方自身の Google アカウント（YouTube チャンネル）に対してだけです。

2. 取得する Google ユーザーデータと利用目的

情報（権限）利用目的
YouTube への動画のアップロード（youtube.upload） 当方のチャンネルに、説明動画・題名・説明文・サムネイル画像を投稿する
YouTube アカウント情報の閲覧（youtube.readonly） 投稿先のチャンネル名と ID を確かめ、意図しないチャンネルに投稿しないようにする
認証情報（OAuth のアクセストークン・リフレッシュトークン） 上記の投稿と確認を、当方がその場で操作しなくても行えるようにする

本ツールは、動画の削除・編集、コメントや再生データの取得、視聴者の情報の取得を行いません。取得した情報を、上記以外の目的（広告、販売、AI モデルの学習など）に使うことはありません。

3. 保存と安全管理

認証情報は、当方のコンピューターの中に、当方だけが読める設定で保存し、当方以外のサーバーには保存しません。Google との通信は暗号化（HTTPS）されます。認証情報は、画面や記録（ログ）にも表示しません。

4. 第三者への提供・広告・クッキー

当方は、本ツールで取得した情報を第三者に提供しません（法令に基づく場合を除きます）。情報のやりとりは、当方と Google（YouTube）とのあいだだけです。本ツールは、第三者による広告などのコンテンツを表示せず、クッキーなどを利用者の端末に保存したり読み取ったりしません。

5. Google API サービスのユーザーデータに関するポリシーの遵守

本ツールによる、Google API から受け取った情報の使用および他のアプリへの転送は、限定使用の要件を含む「Google API サービスのユーザーデータに関するポリシー」に従います。

6. YouTube API サービスの利用

本ツールは YouTube API サービスを利用しています。本ツールの利用には「YouTube 利用規約」が適用されます。Google による情報の取扱いについては、「Google プライバシーポリシー」をご覧ください。

7. 許可の取り消しとデータの削除

本ツールへの許可は、Google のセキュリティ設定のページ（https://security.google.com/settings/security/permissions）から、いつでも取り消せます。取り消すと、本ツールは YouTube に投稿できなくなります。当方のコンピューターの中の認証情報は、許可の取り消しのあとに当方が削除します。

8. 改定

当方は、必要に応じて本ポリシーを改定します。改定後の内容は、本ページに掲示した時点から適用されます。
